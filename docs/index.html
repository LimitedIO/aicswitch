aicswitch

Make AIC8800 WiFi 6 / Bluetooth USB dongles work on Linux.

Cheap WiFi 6 USB dongles built on the AICSemi AIC8800D80 chip show up on Linux as a tiny USB disk (1111:1111 Pandora International Ltd. 88M80) holding a Windows installer, instead of a network card. aicswitch sends the dongle the same vendor command the Windows tool uses, so it turns into a real WiFi + Bluetooth adapter. A udev rule does this automatically every time you plug it in.

Install

Switcher plus the WiFi/Bluetooth driver (recommended):

curl -fsSL https://limitedio.github.io/aicswitch/install.sh | sudo sh -s -- --driver

Only the switcher, if you already have an AIC8800 driver:

curl -fsSL https://limitedio.github.io/aicswitch/install.sh | sudo sh

Then unplug the dongle and plug it back in. To remove aicswitch, run the same command with -s -- --uninstall.

Is this my dongle?

$ lsusb
Bus 001 Device 120: ID 1111:1111 Pandora International Ltd. 88M80

After switching, it shows up as a69c:8d80 aicsemi AIC Wlan, and as a69c:8d81 AICSemi AIC 8800D80 once the driver has loaded its firmware.

How it works

  1. The dongle starts in "driver CD" mode as a USB mass-storage device.
  2. udev sees the 1111:1111 SCSI device and runs aicswitch /dev/sgN.
  3. aicswitch sends the vendor SCSI command FD 00 … 00 F2 through SG_IO. This command was found by disassembling Usb_Driver.dll from the dongle's own Windows installer.
  4. The dongle reconnects as a69c:8d80, and the AIC8800 driver loads its firmware.
